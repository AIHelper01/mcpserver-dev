# w-File Workbench MCP 验证记录

[English](../../../english/02_mcp/cases/02_file-mcp-server/TESTING.md) | 简体中文

验证平台为 Windows、Python 3.12。测试在临时目录中隔离文件和服务状态，
不修改真实的 `D:\files` 或现有恢复历史。

## 运行命令

在本目录安装 `mcp>=1.12,<2` 和 `python-dotenv` 后执行：

```bash
python -B test_file_lifecycle.py
python -B test_file_http.py
```

在父级 `mcp` 目录安装 `requests` 后执行：

```bash
python -B test_bilingual_tools.py
```

生命周期测试 20 项，HTTP 中英文端到端测试 1 项，联合中英文回归 7 项，
共 28 项通过。专题完整回归另包含天气、时间、基础示例和 Skill 对比，合计 51 项。

## 覆盖范围

| 范围 | 验证内容 |
| --- | --- |
| 语言 | 默认英文、显式中文；中英文路径与内容；字段和错误码稳定 |
| 编码 | UTF-8、GB18030、LF/CRLF、多字节边界和分段读取 |
| 写入 | 不覆盖已有目标；无效 Unicode 或发布失败时保留原文件 |
| 删除 | 二进制保真、目录拒绝、备份失败、外部更新检测、容量和回滚 |
| 恢复 | 不覆盖、校验哈希、中断后不留部分目标、可重试 |
| 历史 | 保留损坏历史；历史写入失败回滚；拒绝撤销已被替换的文件 |
| 连续操作 | 重命名、删除、恢复删除、撤销重命名 |
| 并发 | 12 个线程和 4 个工作进程的历史记录完整 |
| 批量 | 默认预览、计划校验、冲突检测和部分失败报告 |
| 快照 | 完整对话回放、字节比对、空目录、类型变化、过期计划和损坏备份 |
| 保留策略 | 记录查询、默认预览清理、计划校验和保留未完成删除记录 |
| 错误 | 权限错误返回本地化结构化响应 |
| 协议 | 工具 schema、实际子进程服务和 HTTP 客户端的中英文流程 |

HTTP 测试使用临时本地端口、独立 `FILE_MCP_STATE_DIR`，Windows 子进程隐藏运行，
测试结束后停止该测试进程。

## 限制

Linux/macOS 的 POSIX 锁与链接重命名分支未在本轮实测。文件系统不支持硬链接时返回错误。
服务锁只能协调使用同一状态目录的参与进程，无法同步任意外部写入或避免所有句柄竞争。
进程终止或断电可能留下待完成记录、暂存或隔离文件。

多文件操作报告部分进度，不承诺目录级事务。快照保存文件字节、目录结构及可复制的 stat 元数据，
不等同于完整 ACL、所有权或备用数据流备份。
